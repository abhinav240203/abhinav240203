## 🚀 Featured Robotics Projects

* **[Robot Path Planning with Costmap](https://github.com/abhinav2403/Robot-Path-Planning-With-Costmap):** Engineered $A^*$ and Dijkstra global path-planning algorithms integrated directly into a ROS 2 costmap framework with real-time TF2 transformations and RViz visualization[cite: 6].
* **[SLAM Toolbox & Robot Navigation](https://github.com/abhinav2403/SLAM-Toolbox):** Deployed SLAM Toolbox and Nav2 map servers in ROS 2 to execute real-time grid mapping, localization, and persistent lifecycle management[cite: 6].
* **[PD Motion Planner & Pure Pursuit](https://github.com/abhinav2403/PD-Motion-Planner-Controller-Pure-Pursuit):** Implemented a curvature-adaptive Pure Pursuit path-tracking controller using AMCL localization to translate global paths into precise velocity commands[cite: 6].
* **[Articulated Robot Design & Kinematics](https://github.com/abhinav2403/Articulated-Robot-Design):** Modeled an articulated robotic manipulator in MATLAB/Simulink featuring custom forward/inverse kinematics solvers and multi-body trajectory simulations[cite: 6].
* **[Robotic Gripper SolidWorks Assembly](https://github.com/abhinav2403/Robotic-Gripper-SolidWorks):** Designed a two-finger mechanical robotic gripper with interconnected links and synchronized gear mechanisms tested through comprehensive assembly mates[cite: 6].
