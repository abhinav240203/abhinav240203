## ⚡ About Me

I'm a **Master's student in Robotic Systems Engineering at RWTH Aachen University**, with a background in Mechanical Engineering.

My interests lie in building and understanding robotic systems across the full stack  from **robot kinematics and control** to **navigation, localization, motion planning, and simulation**.

I mainly work with **ROS 2, C++, Python, MATLAB/Simulink, Gazebo, RViz, and SolidWorks**, with a focus on developing practical robotics systems through simulation and implementation.

# 🚀 Selected Robotics Projects

### 🗺️ Robot Path Planning with Costmap

**ROS 2 · A* · Dijkstra · Costmaps · TF2 · RViz**

Implemented global path-planning algorithms within a ROS 2 costmap-based navigation environment.

* A* and Dijkstra global path planning
* Costmap-based obstacle handling
* Collision-aware path generation
* TF2 coordinate transformations
* ROS 2 integration
* RViz visualization

**[View Project →](https://github.com/abhinav240203/Robot-Path-Planning-With-Costmap)**

---

### 🎯 Motion Planner & Pure Pursuit Controller

**ROS 2 · Python · Pure Pursuit · PD Control · AMCL · TF2**

Developed a path-tracking system for autonomous robot navigation using localization and feedback control.

* Pure Pursuit path tracking
* Configurable look-ahead distance
* PD-based motion control
* AMCL-based localization
* TF2 transformations
* Velocity command generation
* RViz visualization

**[View Project →](https://github.com/abhinav240203/PD-Motion-Planner-Controller-Pure-Pursuit-)**

---

* Odometry data analysis
